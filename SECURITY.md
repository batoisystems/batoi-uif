# Security Policy

Report security issues privately to the Batoi maintainers before public disclosure.

Browser packages must remain UI-only for privileged actions. Server-side RAD, AI, MCP, billing, identity, and data-access decisions must be enforced by application backends.

Use [GitHub private vulnerability reporting](https://github.com/batoisystems/batoi-uif/security/advisories/new) to contact the maintainers privately. Include the affected UIF version, relevant configuration and a minimal reproduction. Do not post secrets or sensitive reproduction details in public issues.
